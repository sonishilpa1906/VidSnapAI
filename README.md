# Project Overview

A Python-based application that automatically generates short video reels from user-provided images and text.

### Features

* 🖼️ **Image Input** – Allows users to upload/select multiple images.
* 📝 **Text Input** – Accepts user-provided text to be included in the reel.
* 🔊 **Text-to-Speech** – Converts the provided text into speech and uses it as background narration.
* 🎬 **Reel Generation** – Combines images, text, and generated audio to create a complete video reel.
* 🖼️ **Gallery** – Displays the generated reels in a gallery for easy preview and access.

### How It Works

1. User provides images and text.
2. The application converts the text into speech.
3. Images are combined with the generated narration.
4. A video reel is created automatically.
5. The generated reel is displayed in the gallery.
